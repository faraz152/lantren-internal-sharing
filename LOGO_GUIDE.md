# Lantern Share logo assets

The Lantern mark is a clean vector lantern and spark with the project's deep green and warm gold colors. The same mark is used for the installed Windows web app, the Android icon, and the Mac app built from `mac/build-dmg.sh`.

## Included files

- `public/brand/lantern-mark.svg` — scalable standalone mark for web, documents, and future platform builds.
- `public/brand/lantern-lockup.svg` — horizontal mark and Lantern Share wordmark for headers and presentations.
- `public/brand/lantern-mark.png` — 512-pixel app icon source; the Mac build turns it into a multi-size `.icns` file.
- `public/brand/lantern-mark-192.png` — compact web app and shortcut icon.

The Mac app and Android APK use the standalone mark. The Windows PWA uses the same mark through its web app manifest. This keeps the visual identity consistent without separate third-party icon assets.
